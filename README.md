# Es La Vira — Shopify theme

A single-product landing-page theme for ES LA VIRA Black Truffle Collagen Oil: gallery + buy box with bundle picker, sticky add-to-cart, scrolling text, icon highlights, image-with-text, stat rings, ingredient cards, how-to steps, comparison table, reviews, guarantee banner and FAQ. Every section is editable in the Shopify theme editor.

## Install

**Option A – GitHub:** Shopify admin → Online Store → Themes → Add theme → Connect from GitHub → pick this repository and branch.

**Option B – ZIP:** zip the `assets`, `config`, `layout`, `locales`, `sections`, `snippets` and `templates` folders and upload under Add theme → Upload zip file.

## After installing

1. Add your product with its photos (Products → Add product). The product page uses them automatically.
2. Themes → Customize: set images for the hero, image-with-text and ingredient cards; edit all sample copy to match your real formula.
3. Bundle discounts: the bundle picker only sets the quantity and shows the price. Create matching automatic discounts under Discounts → Amount off products → minimum quantity (e.g. 2 items = 10%, 3 items = 20%).
4. Replace the review placeholders with real customer reviews, or remove the section.
5. Create menus named `main-menu` and `footer` under Content → Menus.
